# ADR 0003 — Untrusted Generated Code Is a Separate Security Boundary

**Status:** mandatory design constraint; implementation and security validation pending.
**Date:** 2026-11-13.

## Context

A prompt-driven development platform runs arbitrary dependency scripts, application code, shell commands and browser previews supplied by customers or generated by models. Treating these as ordinary backend tasks risks platform compromise and cross-tenant access.

## Decision

Run untrusted workloads in isolated, time-limited, least-privilege workspaces with constrained network egress, disk/CPU/RAM, explicit file mounts and zero platform secrets. Route previews through an authenticated, separately originated proxy. Compare SDK workspace provisioning with a reviewed sandbox product before selecting one production isolation mechanism.

## Consequences

More operational work but non-negotiable for safe public operation. A basic Docker container alone is not an adequate security guarantee. Security gate tests and an explicit review are prerequisites for public user code execution.
